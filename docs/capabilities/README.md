# Capabilities

Capability specifications and the local machine-readable ledger (`index.json`) for `drosera`.
The family timeline, roadmap, and cross-repository capability registry live in the [hub timeline](https://github.com/Vidoxlabs/docs/blob/main/docs/timeline/README.md) on `Vidoxlabs/docs`.
Any code or contract change updates `docs/capabilities/index.json`, the owning capability spec, and `docs/CHANGELOG.md` in the same PR.
