# Architecture Decision Records

Architecture decision records (ADRs) for `drosera` follow the shared [hub ADR convention](https://github.com/Vidoxlabs/docs/blob/main/docs/adr/README.md) in `Vidoxlabs/docs`.

- Filenames in this directory are numbered sequentially from `0001` using the form `NNNN-<slug>.md` (for example `0001-example-decision.md`).
- New ADRs use the hub [ADR template](https://github.com/Vidoxlabs/docs/blob/main/docs/adr/template.md) with `Status: Proposed`; only an explicit owner decision moves an ADR to `Accepted`.
- Any runtime or tooling dependency proposal requires an ADR here before a package is added.
